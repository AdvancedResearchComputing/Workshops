# Virginia Tech (VT) Advanced Research Computing (ARC) Workshops

This repo holds markdown versions of materials 
used in VT workshops each semester and summer.

These workshops are constructed and presented by ARC.

Materials are updated as workshops are given.

Everyone is welcome to work through the materials and use
example codes.

There are materials for workshops herein that are not given every semester.

We welcome any comments that help us improve these workshops.
Please enter your comments at [https://arc.vt.edu/help](https://arc.vt.edu/help).

Our Virginia Tech ARC Workshops web page is here: 
[https://docs.arc.vt.edu/usage/workshops.html#workshops](https://docs.arc.vt.edu/usage/workshops.html#workshops)

Users may wish to visit that site to see listings of our workshops,
in reverse time order.
Each entry in a table is a workshop that contains the workshop title and links
to video recordings and these workshop materials.
